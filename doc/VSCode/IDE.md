# IDE

- [[VSCode]]

**IDE** (Integrated Development Environment) — это среда разработки, которая объединяет в одном интерактивном пространстве всё необходимое для написания, сборки, отладки и тестирования кода. Для embedded-разработчика выбор IDE — это не вопрос вкуса, а вопрос **выживания**.

## Почему IDE, а не текстовый редактор?

Конечно, можно писать код в Nodepad(++) или [[Vim]], собирать через [[Makefile]] в терминале, прошивать через отдельную утилиту, а отлаживать через [[GDB]] в консоли. Но:

- **Переключение контекста** — каждая смена окна крадёт время
- **Ошибки** — легко перепутать флаги компиляции или адрес прошивки
- **Отладка** — без визуализации регистров и памяти это ад
- **Требования к квалификации** — красноглазый линуксоид, который работает только в консоли, давно уже редкая птица, и чаще всего клюнутая
