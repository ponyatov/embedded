# Динамический анализ

Это проверка поведения программы **во время её выполнения** (в *рантайме*). Сюда входят все виды тестирования и инструменты для обнаружения проблем, которые проявляются только в процессе работы приложения.

- **Модульные тесты (Unit Tests)**: проверяют отдельные функции и модули изолированно.
	- [[Python/pytest]]
- **Интеграционные тесты (Integration Tests)**: проверяют взаимодействие между разными компонентами системы.
- **Сквозные тесты (E2E)**: имитируют действия пользователя и проверяют работу всей системы целиком.
- **Профилирование (Profiling)**: измеряет потребление ресурсов (время выполнения, память) для поиска узких мест в производительности.
- **Фаззинг (Fuzzing)**: подаёт на вход программе случайные или искажённые данные, чтобы выявить сбои и уязвимости.
- **Инструменты обнаружения ошибок памяти**:
	- [[C++]]: [[Valgrind]] и [[AddressSanitizer]] находят утечки памяти, ошибки работы с указателями и состояние гонки (race conditions).

Динамический анализ выявляет сложные логические и поведенческие ошибки, которые не были обнаружены при отладке
