# список пакетов для проекта

- файлы `apt.*` содержат списки пакетов операционной системы, которые требуются **для разработки** и отладки
- **для запуска** готовых программ должны применяться *штатные средства установки ПО и контроля зависимостей*: сборка дистрибутивных пакетов, инсталляторов, и механизмы [[git/CICD|CI/CD]] для автоматического обновления ПО

## [[Linux/Linux|Linux]]

### `./apt.Debian`

- для ноутбука/рабочей станции разработчика
	```
	g++ cmake pkg-config clang-format
	gdb gdbserver valgrind doxygen
	```
	- [[C++]]
	- [[CMake]]
	- [[Valgrind]]
	- [[doxygen]]

- при использовании в ваших программах текстовых протоколов и форматов данных, скриптов, файлов конфигурации также включает набор пакетов:
	![[syntax/apt]]
- для тестирования и вспомогательных скриптов часто включают:
	![[Python/apt]]
- при разработке игр или низкоуровневых графических программ:
	![[SDL/apt]]

### `./apt.Ubuntu`

- для (виртуального) сервера или Docker-контейнера

### `./apt.Msys`

- для среды MinGW/MSYS (кросс-разработка под Windows)
