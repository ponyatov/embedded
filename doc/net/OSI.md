# OSI

Эталонная **модель OSI** (Open Systems Interconnection) — это концептуальная эталонная модель, которая описывает, как данные передаются от одного устройства к другому по сети. Она была разработана Международной организацией по стандартизации (ISO) в 1984 году.

Главная цель модели — разделить процесс передачи данных на **7 уровней**. Каждый уровень отвечает за свою конкретную задачу и взаимодействует только с соседними уровнями.
