# L4 [[OSI]]
## Транспортный (Transport)

_Надежность доставки и управление потоком._

- **Что делает:** Отвечает за сквозную доставку данных между конечными точками (приложениями). Контролирует целостность данных, разбивает большие объемы на сегменты и собирает их обратно. Управляет скоростью передачи (чтобы не перегрузить приемник).
    
- **Протоколы:**
    
    - **[[TCP]]** (гарантирует доставку, контролирует ошибки, устанавливает соединение).
        
    - **[[UDP]]** (быстрая передача без гарантии доставки, без установки соединения, базовый режим [[broadcast]]).
        
- **Единица данных:** Сегмент (для TCP) / Дейтаграмма (для UDP).
